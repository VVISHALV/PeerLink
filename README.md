# PeerLink

Peer-to-peer chat and file sharing between devices. No server involved.

## How to connect

Connection details are exchanged manually by copy and paste.

1. **Device 1:** Click **Create offer and copy**. Send the offer to Device 2.
2. **Device 2:** Click **Apply offer and copy answer**. Send the answer back to Device 1.
3. **Device 1:** Click **Apply answer**. You are now connected.
